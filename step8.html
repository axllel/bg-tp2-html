1. Précurseurs et idées fondatrices

Vannevar Bush et le Memex (1945)

En 1945, Vannevar Bush imagine le Memex, une machine permettant de stocker des documents et de créer des liens entre eux. Cette idée annonce certains principes de l'hypertexte.

Ted Nelson et l'hypertexte

Ted Nelson développe le concept d'hypertexte et imagine le projet Xanadu. L'hypertexte permet de relier des informations entre elles grâce à des liens.

2. Naissance du Web (Berners-Lee) et premières implémentations

Tim Berners-Lee et la naissance du Web

Tim Berners-Lee travaille au CERN et propose en 1989 un système permettant de partager des informations à travers un réseau. Il développe les bases du World Wide Web.

Les premières technologies du Web

Le Web repose sur plusieurs technologies fondamentales :

  • HTML : langage de description des pages Web.
  • HTTP : protocole de communication entre client et serveur.
  • URI et URL : systèmes permettant d'identifier et de localiser les ressources.

Les premiers navigateurs et le développement du Web

La première page Web apparaît en 1991. Ensuite, des navigateurs comme Mosaic et Netscape contribuent à la popularisation du Web. Le W3C participe à la standardisation des technologies Web, tandis que les moteurs de recherche facilitent l'accès aux informations.

3. Le Web sémantique, Linked Data et Solid

Le Web sémantique

Le Web sémantique vise à rendre les données du Web compréhensibles par les machines afin de faciliter leur traitement et leur exploitation.

Parmi ses principales technologies :

  • RDF (Resource Description Framework)
  • OWL (Web Ontology Language)
  • SPARQL
  • Microformats
  • JSON-LD

Linked Data

Linked Data désigne un ensemble de bonnes pratiques permettant de publier et de relier des données structurées sur le Web.

Source : The Linked Data Wiki

Solid : vers un Web décentralisé

The Web as I envisaged it, we have not seen it yet.
— Tim Berners-Lee

Solid est un projet visant à redonner aux utilisateurs le contrôle de leurs données personnelles. Il permet de séparer les données des applications qui les utilisent.

Avantages de Solid

  • Les utilisateurs contrôlent leurs données.
  • Les données peuvent être utilisées par différentes applications.
  • Le système favorise la décentralisation.

Limites de Solid

  • Son adoption reste un défi.
  • Sa mise en œuvre peut être complexe.

Les changements de paradigme

Selon Ruben Verborgh, trois changements sont nécessaires :

Three paradigm shifts we need to prepare for:
  • End users become data controllers.
  • Apps become views.
  • Interfaces become queries.

Les cas d'utilisation du Web sémantique

Le Web sémantique peut être utilisé pour organiser les connaissances, relier des données provenant de différentes sources et améliorer la recherche d'informations.
